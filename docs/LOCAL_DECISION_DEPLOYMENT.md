# 로컬 판정 자원 배포 기록

## 배포 판정

구어체 어미 축 하나를 보강한 뒤 증강 자료로 가중치를 새로 생성해
`VoiceCommand/resources/decision/`에 반영했다. 임계값 0.92와 margin 0.30은 바꾸지 않았다.

아래 수치는 이 기록을 작성하면서 직접 실행한 결과다.

### 시험 파티션 (n=3,551)

| 게이트 | selected | coverage | selective accuracy | false_direct | unknown 오선택 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 없음 | 1,754 | 0.4939 | 1.0000 | 0 | 0 |
| 기존 규칙 | 1,654 | 0.4658 | 1.0000 | 0 | 0 |
| 직접 실행 정책 | 1,650 | 0.4647 | 1.0000 | 0 | 0 |

정확도 0.8082, ECE 0.0470, Brier 0.2494. 언어별 정확도는 한국어 0.8057,
영어 0.8645, 일본어 0.7718이다.

직전 배포본과 비교하면 정확도가 0.8049에서 0.8082로 0.33%p, 직접 실행 정책
coverage가 0.4591에서 0.4647로 0.56%p 올랐다. ECE는 0.0451에서 0.0470으로
0.0019 나빠졌으나 허용 범위 안이고, false_direct_count는 모든 게이트에서 0을
유지했다.

### 예비 파티션 (n=369)

| 게이트 | selected | coverage | selective accuracy | false_direct | unknown 오선택 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 없음 | 60 | 0.1626 | 0.9500 | 3 | 1 |
| 기존 규칙 | 57 | 0.1545 | 0.9474 | 3 | 1 |
| 직접 실행 정책 | 48 | 0.1301 | 0.9375 | 3 | 1 |

정확도 0.5772, ECE 0.0695, Brier 0.5525. 언어별 정확도는 한국어 0.6423,
영어 0.5772, 일본어 0.5122다.

예비 파티션은 시험 파티션과 달리 오선택이 남아 있다. 같은 명령으로 직전 배포본을
측정해도 세 건 모두 동일하게 나오므로 이번 변경이 만든 회귀가 아니다.

| 입력 | 정답 | 예측 | confidence |
| --- | --- | --- | ---: |
| `Close the Chrome window` | close_app | focus_window | 0.982 |
| `Chromeのウィンドウを閉じて` | close_app | focus_window | 0.991 |
| `크롬을 켜고 유튜브에서 재즈를 찾아 재생해줘` | unknown_or_complex | play_youtube | 0.995 |

앞의 두 건은 창을 가리키는 낱말이 판정을 지배해 닫기 요청을 전환 요청으로 읽는다.
세 번째는 두 단계를 묶은 요청인데 기존 규칙 게이트가 단일 요청으로 통과시킨 뒤
뒷부분만 읽는다. 예비 파티션은 학습에서 격리한 평가 전용 자료이므로 이 세 건에
맞춰 학습 자료를 넣지 않았다. Phase 5에서 인자 해석과 안전 정책을 붙일 때 다뤄야 할
근거로 남긴다.

버킷 8,192개, 보정값 양수 조건을 확인했다. 생성 중 런타임 쓰기 경로는 임시 디렉터리로
격리했다.

## 단계 경계

Phase 1은 정책과 호출 배선 기준으로 완료로 판정한다. 허용 목록, 영구 금지 목록,
`off`·`shadow`·`fast`·`adaptive` 모드와 기본 `shadow` 값이 연결되어 있다.

직접 실행 자체는 Phase 5 경계에 둔다. 현재 판정 결과는 메모리에 보관하고, 인자 해석과
안전 정책 검증이 끝나기 전에는 판정만으로 실행하지 않는다. 따라서 이번 배포는 판정
품질 자료와 판정 자원을 갱신한 것이며 기존 실행 경로의 안전 절차를 우회하지 않는다.

## 검증

다음 명령을 Python 3.11 실행 파일로 수행했다.

```text
py -3.11 -m unittest discover -t . -s tests -p "test_*.py"
```

결과는 `Ran 581 tests in 21.048s`, `OK (skipped=1)`, 종료 코드 0이었다.
`ARI_APP_DATA_DIR`는 임시 경로로 격리했고 검증 후 삭제했다.
