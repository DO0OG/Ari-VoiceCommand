# 캐릭터 애니메이션 이미지 가이드

아리(Ari)의 캐릭터 위젯은 정해진 파일명 규칙을 따르는 PNG 이미지 시퀀스로 애니메이션을 만듭니다.
트레이 메뉴나 설정 UI가 늘어나더라도 캐릭터 애니메이션 리소스 규칙은 이 문서를 기준으로 유지합니다.

## 1. 이미지 파일 규칙
- **형식**: 투명 배경을 가진 `.png` 파일
- **파일명**: `{동작이름}{프레임번호}.png` (예: `idle1.png`, `idle2.png` ...)
- **위치**: `VoiceCommand/images/` 폴더

---

## 2. 필수 이미지 리스트 (기본 동작)

| 동작 이름 (Prefix) | 권장 프레임 수 | 설명 |
| :--- | :---: | :--- |
| **idle** | 10 | 가만히 서 있을 때 (기본 상태) |
| **walk** | 10 | 바닥을 걸어 다닐 때 |
| **drag** | 10 | 마우스로 잡고 끌 때 |
| **fall** | 10 | 공중에서 떨어지는 동작 |
| **sit** | 10 | 바닥에 앉아 있을 때 |

---

## 3. 권장 이미지 리스트 (특수 동작)

이 이미지가 없으면 `idle` 또는 `sit` 상태로 대체됩니다.

| 동작 이름 (Prefix) | 권장 프레임 수 | 용도 |
| :--- | :---: | :--- |
| **surprised** | 2 | 놀람, 화남 감정 표현 시 |
| **sleep** | 4 | 평온, 걱정 감정 또는 밤 시간대 |
| **climb** | 6 | 벽을 타고 올라가는 동작 |
| **ceiling** | 4 | 천장에 붙어 있을 때 |

---

아리는 말풍선에 **이모지**를 띄워 조금 더 세밀한 감정을 표현합니다. 감정 태그는 설정된 언어에 따라 자동으로 바뀝니다.

| 감정 (ko / en / ja) | 표시 이모지 | 연결 애니메이션 |
| :--- | :---: | :--- |

| **슬픔 / sad / 悲しみ** | 😭 | sit / sleep |
| **화남 / angry / 怒り** | 💢 | surprised |
| **놀람 / surprised / 驚き** | 😲 | surprised |
| **평온 / calm / 穏やか** | ☕ | idle / sit |
| **수줍 / shy / 恥ずかしい** | ☺️ | sit / idle |
| **기대 / excited / 期待** | ✨ | walk / idle + 점프 |

## 5. 제작 팁

- **방향**: **오른쪽**을 바라보는 것이 기준입니다. 왼쪽으로 이동할 때는 자동으로 좌우가 뒤집힙니다.
- **크기**: 200x200px 정사각 캔버스를 기준으로 하며, 프로그램은 원본 크기 그대로 표시합니다.
- **정렬**: 모든 동작은 캔버스 하단에 캐릭터가 닿도록 그립니다. 앉기처럼 키가 작은 동작도 캔버스 아래쪽에 맞춰야 바닥 위치가 어긋나지 않습니다.

---

## 6. 표시 크기와 바닥 위치 조절

`설정 > 장치 설정 > 캐릭터 표시 설정`에서 두 값을 조절할 수 있습니다. 저장하면 즉시 반영됩니다.

| 항목 | 범위 | 설명 |
| :--- | :---: | :--- |
| **캐릭터 크기 배율** | 0.3 ~ 3.0 | 값이 클수록 크게 표시됩니다. 기본값 `1.0` |
| **바닥 보정값** | -200 ~ 200 px | 값을 키우면 아래로 내려갑니다. 기본값 `4` |

캔버스 하단에 여백이 있는 커스텀 이미지를 쓰면 캐릭터가 바닥에서 떠 보입니다. 이때 여백 높이(배율 적용 후 픽셀)만큼 바닥 보정값을 키우면 발이 바닥에 맞습니다. 반대로 캐릭터가 작업표시줄에 파묻히면 보정값을 줄이세요.
