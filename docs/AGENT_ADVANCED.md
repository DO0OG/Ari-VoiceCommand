# 자율 에이전트 고급 기능

- 에이전트는 독립적인 목표를 하위 에이전트에 넘길 수 있고, 동시 실행 개수는 `max_subagents` 설정으로 제한합니다.
- Google Calendar/Gmail, OpenAPI 기반 `api_call`, 이미지 생성 도구는 설정에서 켠 뒤에 쓸 수 있습니다.
- 벤치마크는 `VoiceCommand` 디렉터리로 이동한 뒤 `.venv\Scripts\python.exe -m tests.benchmark_agent`로 실행합니다. 다른 위치에서 실행하면 `core` 모듈을 찾지 못해 실패합니다.

## 대화 문맥과 기분

LLM 요청에는 현재 시각, 마지막 상호작용 이후 경과 시간, 하루 상호작용 횟수,
연속 사용 시간, 최근 칭찬 횟수, 전체 화면 여부와 캐릭터 기분 상태가 상황 정보로
들어갑니다. 앱 활동 정보는 앱 종류와 경과 시간만 사용하며 창 제목이나 프로세스 이름은
포함하지 않습니다.

기분은 대화·작업 결과·자리 비움 후 복귀·선제 발화 반응 등을 바탕으로 갱신되고 시간이
지나면 중립 상태로 돌아갑니다. 저장된 기분은 캐릭터 애니메이션과 대사 선택에 반영됩니다.

## 기억 후보, 검색, 일일 요약

- `fact_extraction_suggestions_enabled`는 기본값 `true`입니다. 설정 → `AI 설정`에서 사용자 발화의 기억 후보 추출을 끌 수 있습니다. 후보는 텍스트 채팅의 기억 패널 → `제안`에서 승인해야 프로필이나 사실에 반영됩니다.
- `memory_search`는 사실, 대화, 일일 요약을 검색할 수 있습니다. 사실은 현재 요청과 관련된 항목을 우선 문맥에 넣습니다. 사실을 지우면 검색 색인, 그 값이 담긴 대화 기록과 일일 요약, 그 값을 포함한 선호 값도 함께 지웁니다(값이 한 글자면 사실만). 색인을 다시 만들어도 대화와 일일 요약은 보존하고 사실·선호만 다시 만듭니다.
- 일일 요약은 예약된 메모리 정리에서 전날 대화가 있고 요약 생성에 필요한 LLM을 사용할 수 있을 때 만들어집니다.
- 의미 검색은 로컬 ONNX 임베더를 기본으로 사용합니다. 원격 OpenAI 임베딩은 `embedding_remote_enabled` 기본값이 `false`이며, 켜면 작업 목표·스킬 목표·에피소드 문맥이 외부 임베딩 API로 전송될 수 있습니다. 설정 경로와 데이터 범위는 [API 키 보관](./CREDENTIALS.md)을 참고하세요.

## 도구 결과 후속 호출

`tool_followup_policy_enabled` 기본값은 `true`입니다. 타이머·앱 실행·스크린샷처럼 단순한
도구 결과가 충분하고 추가 해석을 요청하지 않았다면, Ari는 그 결과를 바로 답할 수 있습니다.
끄려면 런타임 `ari_settings.json`에서 `false`로 설정하세요. 이 값은 설정 화면에 없습니다.

## 네트워크 접근 제한

- `web_fetch`, 원격 MCP 호출, 이미지 다운로드는 공개 인터넷 주소로만 요청합니다. 사설·루프백·링크 로컬 주소와 `0x7f.1` 같은 변형 표기는 거부하고, 리디렉션될 때마다 다시 확인합니다.
- 응답은 `web_fetch` 2MB, MCP 10MB, 이미지 30MB까지 받으며 압축 응답은 푼 크기로 셉니다. 원격 MCP와 이미지 다운로드는 HTTPS만 허용합니다.
- 브라우저 자동화는 `localhost`처럼 직접 지정한 로컬 주소를 열 수 있습니다. 공개 페이지에서 클릭·제출 뒤 로컬 주소로 넘어가면 빈 페이지로 돌리고 오류로 처리하는데, 이 확인은 페이지가 이동한 뒤에 이뤄집니다.
- NAT64 주소(`64:ff9b::/96`)에 담긴 사설 IPv4와 `64:ff9b:1::/48`도 거부합니다.
- 시스템 프록시를 쓰는 환경에서도 미리 확인한 공개 IP로 요청합니다. HTTPS는 그 IP로 CONNECT하고 인증서는 원래 이름으로 검증하며, IP 목적지를 거절(403)하는 프록시에서는 이름으로 한 번 다시 시도합니다. 이때는 프록시가 이름을 다시 해석하므로, 그것까지 막으려면 환경 변수 `ARI_PROXY_NAME_FALLBACK=0`으로 재시도를 끕니다. 프록시를 거치는 HTTP 요청에는 이런 재시도가 없습니다.
- 브라우저 자동화가 받은 파일은 다운로드 폴더 아래 전용 임시 폴더(`.ari-browser-*`)에 모았다가 끝난 파일을 다운로드 폴더로 옮깁니다. 이름이 겹치면 `이름 (1).확장자`처럼 번호를 붙입니다.
- OpenAPI 기반 `api_call` 도구에는 이 제한이 적용되지 않습니다.

## 활동 반응과 선제 발화

설정 → `활동 반응`에서 자리 비움·복귀, 화면 잠금, 방해 금지·전체 화면, 앱 종류,
게임 모드와 IDE 장시간 사용 반응을 조정합니다. 앱 종류 반응과 자동 게임 모드는 기본적으로
꺼져 있습니다.

사건 기반 발화 스케줄러는 복귀, 야간 장시간 사용, 작업 완료, 주간 보고서와 정리 결과 등에
따라 짧은 대사를 예약합니다. 언어와 기분에 맞는 문구를 고르고 하루 횟수와 재생 대기 시간을
제한합니다. 화면 잠금·자리 비움·방해 금지·전체 화면·게임 모드, TTS 재생 또는 에이전트
작업 중에는 발화를 미룹니다.

## 학습 기여도 진단

설정 → `에이전트`의 `학습 기여도 진단`은 학습 구성 요소를 활성화, 판정 보류(표본 부족),
비활성화 상태로 표시합니다. 표본이 충분하지 않을 때는 구성 요소를 효과 없음으로 확정하지
않습니다.
