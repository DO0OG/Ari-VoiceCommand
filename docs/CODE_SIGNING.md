# Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation

## Current status

Ari is at the stage of applying to the SignPath Foundation program. No signed release has been published yet. This document will be updated when a signed release is published.

## Team roles

- Committers and reviewers: [DO0OG](https://github.com/DO0OG)
- Approvers: [DO0OG](https://github.com/DO0OG)

The project has a single maintainer. Outside contributions (pull requests) are reviewed by the maintainer before they are merged.

## What is signed

Only `Ari.exe` and the installer (`Ari-Setup-<version>.exe`), built from the source in this repository by the public GitHub Actions workflow [`.github/workflows/build-release.yml`](../.github/workflows/build-release.yml). Binaries of other projects that are packaged together with Ari (for example, third-party libraries) are not signed by this project.

## Privacy policy

See the [privacy policy](./PRIVACY.md).

## Verifying release files

See [Release verification and antivirus notes](./SECURITY.md).
